# Hệ Thống Quản Lý Đồ Án Công Nghệ Thông Tin (QLDACNTT)

Ứng dụng web hỗ trợ quản lý, theo dõi tiến độ, phân công giảng viên hướng dẫn và lưu trữ báo cáo đồ án dành cho sinh viên và giảng viên khoa Công nghệ Thông tin.

## Tính năng chính
* **Quản lý đề tài:** Đăng ký, duyệt và phân loại đề tài đồ án theo từng học kỳ.
* **Phân công hướng dẫn:** Ghép nhóm sinh viên với giảng viên hướng dẫn và hội đồng chấm thi.
* **Theo dõi tiến độ:** Cập nhật các mốc báo cáo hàng tuần, nộp mã nguồn và tài liệu báo cáo.
* **Chấm điểm & Đánh giá:** Nhập điểm quá trình, điểm phản biện và tổng hợp kết quả tự động.

## Công nghệ sử dụng
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript
* **Backend:** PHP (Mô hình MVC)
* **Cơ sở dữ liệu:** MySQL (InnoDB)
* **Công cụ quản lý mã nguồn:** Git & GitHub
